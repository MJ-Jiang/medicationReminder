ReminderDatabaseHelper

open class ReminderDatabaseHelper

ReminderDatabaseHelper is a SQLiteOpenHelper subclass used to manage database creation and version management for the reminder application. It provides methods for inserting, updating, and querying reminders and reminder groups.

It relies on ReminderQueryHelper for most database constants and helper queries.
