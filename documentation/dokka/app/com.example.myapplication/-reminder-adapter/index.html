ReminderAdapter

open class ReminderAdapter

ReminderAdapter is a RecyclerView adapter responsible for displaying a list of reminders in a RecyclerView. It binds reminder data to views defined in reminder_item.xml layout.

It also handles item click events and checkbox state changes using the OnReminderClickListener interface.
