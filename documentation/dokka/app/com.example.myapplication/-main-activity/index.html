MainActivity

open class MainActivity : ReminderAdapter.OnReminderClickListener

MainActivity is the main screen of the reminder app. It displays a list of reminders for the selected date, allows the user to select dates, create new reminders, and access settings.

This activity uses a RecyclerView with a ReminderAdapter to show reminders and listens for reminder item clicks and completion changes.

It also periodically checks for reminders that need notification using ReminderNotifier.

Language settings are applied dynamically when attaching the base context.
