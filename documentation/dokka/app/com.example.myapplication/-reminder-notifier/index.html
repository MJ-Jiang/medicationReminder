ReminderNotifier

open class ReminderNotifier

ReminderNotifier handles checking reminders for the current day and notifying the user at the appropriate times using Android AlertDialogs.

It queries the database for today's reminders, checks their completion and notification status, and shows a notification dialog if it's time to remind the user.
