Medicine Reminder App - Design Document
1. Overview
The Medicine Reminder App is a mobile application developed using Android Studio with Java. It helps
users manage their medication schedules efficiently by providing reminders, tracking progress, and
allowing customization through user settings.

While designing the Medicine Reminder App, my main focus is to strengthen my skills in Android development
using Java and Android Studio, as emphasized in the course exercises. I aim to learn how to design
a functional and user-friendly application that serves a real-world purpose.
Specifically, I want to improve my understanding of how to:
• Structure an Android app with clear separation of concerns between different classes (such as UI, database access, and logic),
• Design intuitive and accessible user interfaces,
• Integrate and manage a local SQLite database to store and query reminder data efficiently,
• Implement background tasks such as time-based notifications reliably.

2. Features
2.2 Pill Reminders
• Create New Reminder:
    o Users can set reminders with a start date and end date.
    o Frequency options: Daily, Weekly, Monthly and Yearly, and Multiple times a day.
    o Validation checks: Ensure all required fields are filled before adding a reminder.
• View and Manage Reminders:
    o Reminders are sorted in chronological order.
    o Users can select different dates, and the interface will display reminders for the corresponding dates.
    o Users can mark a reminder as "done."
• Notifications:
    o Timed alerts when a medication needs to be taken.

2.3 Progress Tracking
• Users can generate records of completed reminders.
• Provides daily, weekly, and monthly completion rate tracking.
• Displays visual representations of medication adherence.

2.4 Settings Menu
o Preferred language (Localization support for at least two languages)
o Progress Chart
